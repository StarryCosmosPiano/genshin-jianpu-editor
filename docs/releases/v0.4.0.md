# v0.4.0 更新说明（2026-09-24）

本版新增以谱面为主的可视化打谱工作区，同时加强了多声部文本谱、三连音往返、长谱编辑和格式转换。项目显示名称统一为**原琴助手编辑器**。原有的谱面直接编辑、JPW、MIDI、MusicXML、ABC、图像识谱、播放和导出能力继续提供；它们并非本版首次加入。

## 与 v0.3.1 的版本对比

核对基线为 GitHub `origin/main` 的 v0.3.1（`41a1dc7`）。开始核对时，本地 `main` 与该基线 **ahead 0 / behind 0**；当时尚未形成新提交，差异都在未提交工作区。初始盘点有 **67 个已跟踪文件被修改**，文本变更约 **+20,826 / −2,224 行**（统计含已跟踪文件，不含未跟踪文件）；另有 **73 个未跟踪文件**，其中包含临时产物。以上是开始核对时的工作区快照，正式发布的变更范围与数量以最终 GitHub 版本比较为准。

本版使用独立发布标签 `yuanqin-v0.4.0`，避免与仓库保留的上游历史 `v0.4.0` 标签混淆；应用版本仍为 `0.4.0`。

## v0.4.0 追加修复（2026-09-24）

以下修复并入现有 **v0.4.0**，版本号和发布标签 `yuanqin-v0.4.0` 均不变。桌面版用户需要重新下载安装更新后的安装包；在线版用户刷新页面即可获取更新。

1. **保留原有括号写法。** 创建三连音后，未改动的 TXT 拍组保留原文的圆括号，不再被批量改写为花括号；实际编辑过的拍组仍按当前括号设置和节奏语义重新生成。
2. **重叠三连音按声部分别计时。** 两个声部可在同一拍组建立时间范围重叠的三连音，各自的实际起点、成员时值和总范围独立保留；保存重载后不会因共享显示格而合成错误和弦、吞掉音符或误报拍长。
3. **波音正文完整写出。** 第一声部的普通音 A 添加上波音或下波音后，TXT 正文分别写出 `[ASA]`、`[AMA]` 的主音、邻音、主音结构；只有首个 A 占该声部的普通音时值，第二声部的三连音成员和时值不受影响。
4. **两组标记分别显示。** 第一声部从首个 A 建立的短三连音，会显示自己的数字“3”和括号；第二声部较长的重叠三连音也保留自己的标记。只有两个声部实际起止范围完全相同时，才合并重复显示。
5. **按可见笔画选中谱面对象。** 点击命中改用实际字形和线条的紧边界，避免音乐符号字体的空白区域、曲线包围盒的空心区域遮挡附近音符；和弦中的各音、波音符号、三连音数字和括号可分别选中。
6. **打谱点击落在实际音符上。** 打谱模式直接点击普通音符时，采用该音实际声部与起音位置；附近三连音的节奏格不会把点击吸到组内。仅在三连音可见范围内点击空白时，才按该组刻度定位光标。

本轮验证：`npm run check:all`、长谱性能专项与谱面截图检查通过，覆盖三档缩放下的音符/符号点选、括号保留、双声部重叠三连音、波音正文、撤销重做及保存重载。ABC 两个内置样本生成通过，外部真实曲谱与 Python 参考对比仍按下文限制说明处理。新增浏览器回归使用跨平台的 Control/Command 按键，截图写入系统临时目录。

## 谱面编辑与工作区

- 新增可切换的打谱模式：在谱面的节奏位置放置光标，使用数字键或触屏数字键盘输入、替换音符和叠加和弦；可直接调整时值、八度、时间位置与声部。输入时支持短时试听，谱末可在虚拟尾小节继续写谱。
- 打谱模式进入时沿用当前有效的谱面或文本位置；多选和弦、跨页位置、灰色延续音与尚待解析的文本修改均按当前文档重新定位。没有有效位置时等待用户点谱，避免跳到旧文档的光标。
- 选音后可按 `N` 进入打谱；打谱时 21 琴键按键可直接修改活动单音，保留原时值与同和弦其他音。普通选择模式下，选音后按空格可从该音开始连续播放或停止；文本输入和打谱模式保留各自的空格行为。
- 右键编辑扩展到琶音、波音、颤音、三连音、倚音、速度变化、精确换调及谱面文本。点击谱头标题、副标题、署名、调号、拍号或速度，可直接在浮窗中修改并参与文档撤销、重做。
- 主界面改为谱面优先的工具栏、状态栏与可展开文本栏；支持左栏文本/排版样张切换、宽度和左右位置记忆、窄屏抽屉，以及跟随系统、浅色、深色主题。乐谱和排版设置使用可拖动、缩放的悬浮窗口。
- 排版设置先在当前乐谱上预览，应用时才保存；取消可恢复原排版，关闭未应用的设置会提示处理。增加独立快捷键配置，可按场景录入、检查冲突、恢复默认，帮助中的快捷键随配置更新。
- 页面内输入与确认窗口统一处理速度、装饰、谱面文字、设置确认及导出错误；错误在窗口内显示，取消不提交编辑。

## 文本谱、节奏与多声部

- 键盘谱与数字谱 TXT 支持更完整的谱面输入和往返：多个同步声部、声部归属、显式休止与隐式延续、和弦、装饰和隐藏细分格在编辑、转换、撤销及重新打开后尽量保持语义。混合 TXT 可切换当前识别的谱型，未选谱文保留原文。
- 同一份 JPW 中的多个普通 `.Voice` 现在按顺序导入为独立声部；乱序的 RH/LH 或乐器 V1/V2 段仍可正确映射到源码。重复的声部身份会明确报错，避免静默丢谱或编辑错行。
- 修复文档会话和设置撤销：切换文档不会把上一份文件的撤销历史带过来；修改 TXT 声部数、时值符号、括号语义或格式时，文本及解析设置作为一个历史状态恢复。
- 修复附点音创建三连音、空第三格输入、组内改时值与跨声部移动的时值和休止关系。二分音符、全音符等跨拍长三连音按拍输出并可借助元数据还原真实三个成员；读取旧式元数据的兼容路径仍保留。谱面只显示三个实际成员，三连音数字的点击范围不再遮挡下方音符。
- 调整跨小节延音链、同音和弦、音符移动及细时值休止的处理，减少保存和重新解析后发生的音长改变、额外休止或选中音丢失。键盘谱/数字谱内部转换保留开头拍号和更细的显式节奏信息；普通 MIDI 导入界面的量化档位仍以 64 分音符为上限。

## 排版、播放与格式

- 钢琴和总谱改用传统左花括号路径；跨谱行小节线可选择连接，默认关闭。花括号、延音线和圆滑线的默认粗细及调节范围已调整；已有文档中超出新滑条范围的较大花括号自定义值继续保留。
- 排版面板集中纸张、字号、行距、页眉、节奏刻度和钢琴系统等选项。五度圈以 C 为顶端并标出升降号数量，调号与拍号窗口也可拖动、缩放。
- MusicXML 导入、导出补齐拍中调号变化、琶音、波音/颤音和谱面文本的语义传递；图像识谱识出的速度可经中间 MusicXML 保留在可编辑乐谱中。
- 播放中的输入试听按声部音色发声；播放/停止按钮保持固定宽度，翻页时页码跟随更加稳定。

## 长谱编辑性能

- 文本谱解析和源码定位减少全谱重复扫描；修改一处音符时，适用的钢琴双声部乐谱可复用未变谱行，并逐节点更新 SVG。跨页分页、命中区域及模型引用随新谱重新绑定；不适用增量路径的谱型继续完整排版。
- 在 2026-09-23 的同机 Edge 双声部样本中，256 小节、5120 个源音符的末端输入，从优化前的约 **2039 ms** 降至约 **394 ms**；界面改版后相同测试约 **408 ms**，光标导航约 **2 ms**。这是指定样本的单次同机测量，不代表所有设备或乐谱的性能保证；超长谱仍有约 0.4 秒的输入开销。条件、阶段数据和完整重排对比见[长谱编辑性能核对](../长谱编辑性能-2026-09-23.md)。

## 已知限制

- OMR 仍需人工核对倾斜、淡印、水印或复杂装饰音图片。本版没有重新评测识谱准确率；桌面端 Gemini 路径仍依赖本机 `agy`，浏览器端使用本地识别路径。
- MIDI 踏板、力度、弯音和完整连续速度图尚未全部写入简谱模型。无原生 MIDI 后端的平台使用前端播放器。
- 浏览器预选文件夹的能力取决于浏览器的 File System Access API 实现；本地 OMR 基准还需要未提交的测试图片。
- 长谱增量排版主要覆盖符合条件的钢琴双声部节奏布局。单谱、总谱、传统间距及跨声部琶音等仍可能触发完整排版。

## English highlights

- **Additional v0.4.0 fixes:** Creating a triplet preserves unchanged parenthesized TXT groups instead of rewriting them as braces. Overlapping triplets keep independent timing for each voice, and an upper or lower mordent on the first voice writes `[ASA]` or `[AMA]` without altering the other voice’s triplet. A shorter triplet on the first A retains its own visible “3” and bracket. Selection now follows painted glyphs and strokes, and input-mode clicks on ordinary notes no longer snap into nearby triplets. The version and `yuanqin-v0.4.0` tag remain unchanged.
- **Score-first workspace:** A dedicated notation input mode adds rhythm-position entry, chord editing, a touch keyboard, note audition, and direct editing of score headers. The redesigned interface includes light, dark, and system themes, floating settings panels, and configurable shortcuts.
- **More reliable editing:** Multi-voice TXT and JPW handling, cross-beat triplets, ties, fine rests, document history, and source-to-score selection received round-trip fixes. Existing editing and import/export features remain available.
- **Faster long-score updates:** Eligible two-voice piano scores reuse unchanged systems and SVG nodes. In one documented local Edge sample with 256 measures and 5,120 source notes, an edit near the end improved from about 2,039 ms to 394 ms before the interface redesign, and measured about 408 ms afterward. These are sample measurements, not cross-device guarantees.
- **Compatibility:** The app is now displayed as **原琴助手编辑器** while retaining existing score formats, the Tauri identifier, file associations, and storage migration paths. SF2 SoundFonts remain user supplied. See the Chinese sections above for details and known limitations.
