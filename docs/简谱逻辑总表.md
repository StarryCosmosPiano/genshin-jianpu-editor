# 简谱逻辑总表

这是项目中所有会改变**简谱语义、编辑结果、排版结果、播放结果或格式往返结果**的单一维护索引。基线为 2026-08-30 当前工作区代码；表中 ID 永久稳定，用来回答“这次改了哪些逻辑”。

维护规则：

- 行为改变：修改对应行的“现行逻辑 / 不变量”“实现入口”“最低回归”，将版本 `vN` 加一并更新核对日期；提交说明建议带上逻辑 ID，例如 `[JP-INPUT-008] 修复三连音删除`。
- 仅重构、不改行为：版本不变，只更新实现入口和核对日期。
- 新增逻辑：在对应逻辑域末尾增加新 ID，禁止复用或重排旧 ID。
- 删除逻辑：保留原行，把现行逻辑改为“已废弃 → 替代 ID”；这样 Git 历史和问题引用不会失效。
- 查看本次逻辑变化：`git diff --word-diff=plain -- docs/简谱逻辑总表.md`；查看历史：`git log -p -- docs/简谱逻辑总表.md`。
- “最低回归”只是该行的最小集合；跨域改动仍应运行 `npm run check:all`。本地存在 `ai-control.local/` 时，可额外用场景复现真实点选、快捷键和右键操作。
- 表的覆盖边界包括 `src/`、`src-tauri/` 中的项目自有简谱逻辑；`src/jpword/parser/` 作为 ANTLR 生成物归入文法行，不手工逐文件登记；纯 CSS、静态图标和第三方库不视为独立简谱逻辑。
