# 功能状态

当前发布版本：**v0.5.0（2026-10-08）**。本轮五线谱预览、水印导出、内容缩放与三连音往返修复见
[完整更新说明](releases/v0.5.0.md)。

当前源码识别原琴助手虚拟 MIDI 端口用途（2026-10-30）：`YuanQin MIDI Out` 显示为“原琴助手演奏输入”并优先推荐；`YuanQin MIDI Send` 显示为“原琴助手内部发送端”，仅此端口时不默认连接。已有选择保留，一般设备不按 In/Out/Return 字样猜测方向。本机已由用户确认改选 Out 后实际弹奏可写谱。

本轮修正 MIDI 权限窗口返回后残留失焦状态导致已连接却不写音的问题；连接会准备打谱起点，设备窗口显示收信号与暂停原因。MIDI、乐谱、排版与视图移至顶部菜单，桌面工作区选择器居中。
手机/平板的五线谱使用独立音名、科学八度与升降号，简谱保留数字/原琴键盘；对照仅预览，打开单谱后才可打谱，下拉可直接切到可编辑文本谱。文本中完整括号按已配置用途自动更新元数据，与键入一同撤销；尚未配对时保留原文和旧谱，不自动猜测未指定的括号用途。

当前源码新增 MIDI 设备打谱与工具栏和弦模式（2026-10-22）：近同时按键合成和弦，普通输入替换当前音组并前进至实际音尾；和弦模式原位追加，未连接设备时也能用 1–7，按指定成员或整组最高音确定八度，多选分别处理。
键盘谱单成员改音在音高交叉或同音时仍跟随原成员；简谱 Ctrl+Alt+上下按调内音级升降，打谱时 Ctrl 框选累积、Shift 框选替换。五线谱新输入超过后方空隙时自动裁短。
前端核心及设备模拟、选择和输入回归已验证；Windows 原生 MIDI 接口已接入，但本机无 Rust 工具链及实体 MIDI 设备，原生编译和硬件验收尚未完成。

当前源码增加手机/平板专属触屏工作区（2026-10-18）：数字、原琴字母和五线谱音名操作盘，
整页点选定位、平移/捏合、多选/范围/框选与当前拍位记号操作；共享编辑命令及撤销，不改打印排版。
输入默认原位，可选自动前进；横屏操作盘移至右侧，文本和大型表单适配可视视口。
移动文件提供系统分享/下载副本、本机IndexedDB草稿和按页PDF识图；长谱按可见页挂载，音源按需加载并复用，后台停止播放。
浏览器模拟回归与真机验收分开记录：iOS Safari、Android Chrome真机尚需实机核对。

当前源码已加入双谱面共享编辑（2026-10-10）：五线谱键盘与鼠标打谱、简谱多目标事务、
两种谱面共用纸张设置和逐项谱头字号。五线谱按额外75%音乐密度紧凑排版，每行最多4小节；
键盘光标与悬停占位独立，N模式时值仅设置待输入状态，导出可选择是否保留刻度线。
操作与回归入口见 [开发说明](开发.md)。

当前源码更新导出与五线谱样式（2026-10-18）：PNG/PDF 的导出窗口可直接选择简谱或五线谱，
简谱支持当前显示、数字及键盘字母，声部颜色每次默认关闭；水印改为围绕页面中心对称排列的密度档位。
五线谱乐器名仅首行显示，速度等标记贴近所属谱表并避让音符与符杠；短延音线更加清晰并略加粗，
上下加线、大括号和连接线随音乐比例正确缩放。导出使用独立排版副本，不改变当前文档与屏幕谱面。

当前源码新增无斜杠 TXT 导入与“文件→添加斜杠…”（2026-10-12）：读取正文实际符号，
初始时值留空，顶部提示先填写拍号或点击“分析拍号”；给定拍号后优先按一原文行一小节试算，导入首次填写拍号且未手改时值时只自动填一次，手改保持。
补斜杠保留原文字符与换行，首行不足整小节时前补休止。确认补斜杠后进入导入设置，
两步窗口右侧默认真实 SVG 简谱，可切换只读文本谱；第二步按第一步固定音长等长换写目标时值符号，目标过粗时提示所需最短时值并阻止导入。窗口外不可操作，不误退、不提示保存，最终确认才替换文档；拍号留空时先手填时值再分析候选。

## 已完成

本轮修复休止符内部拍位按Delete/退格误切分正文：0、0.25、0.5、0.75拍位均保持原文，保留0休止符时同样适用。框选播放恢复原有简谱金色光晕、文本淡紫底色与紫色下划线，选区样式不再盖住播放高亮；不添加独立光标。关闭“保留0休止符”时不再把预期的前音延长误报为精度不足，开头静默保留。再次按N退出打谱回到选择模式。

当前源码新增选择、打谱、播放及恢复保护（2026-10-12）：谱面支持查看/选择/打谱三态，
选择状态仅调整声部和播放，双谱面空白可框选，切回打谱保留选区及上次光标。
同拍选音才试听，琶音保留起音差；框选/多选限定播放并在选中音结束时自动停止。
文本、简谱、五线谱分别跟随播放，手动滚动可暂时暂停；五线谱采用浅紫选中与深紫细虚线符头，
修正变音符号比例。清空括号同步迁移正文，取消三连音无法精确表示或超拍时完整拒绝。
未保存关闭/替换有保护；桌面自动保存默认关闭，保存正式文件后可按默认2分钟保留最多10份近似等比分布恢复副本。
原生备份提供原子清单、受限清理与历史恢复，未完成或语法错误的原文也可逐字恢复为未保存副本。
解除外层三连音时保留仍启用的内层细分分组及全部成员；源模型尚不支持的普通嵌套三连音会提示先处理内层。
本机无Rust工具链，原生编译及单测需在具备工具链的环境运行。

## 已知限制

- 无斜杠文本只有总时值不能唯一确定拍号或符号映射；候选需人工核对。数字谱 `+/-` 的八度与时值歧义需明确选择，缺时值音须补全。
- MIDI 踏板、力度、弯音和完整连续 tempo map 不全部写入简谱模型。
- OMR 仍受图片倾斜、淡印、水印和复杂装饰音影响，需要人工核对。
- Gemini OMR 仅桌面端可用，并依赖本机 `agy`。
- Windows/Linux 没有原生 MIDI 后端时使用前端播放器。
- 浏览器 File System Access API 的文件夹预选能力因浏览器实现而异。
- 本地 OMR benchmark 需要未提交的 `testdata/`。
