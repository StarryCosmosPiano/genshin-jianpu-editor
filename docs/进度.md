## 已知限制

- MIDI 踏板、力度、弯音和完整连续 tempo map 不全部写入简谱模型。
- OMR 仍受图片倾斜、淡印、水印和复杂装饰音影响，需要人工核对。
- Gemini OMR 仅桌面端可用，并依赖本机 `agy`。
- Windows/Linux 没有原生 MIDI 后端时使用前端播放器。
- 浏览器 File System Access API 的文件夹预选能力因浏览器实现而异。
- 本地 OMR benchmark 需要未提交的 `testdata/`。

实现结构见 [技术栈.md](技术栈.md)，验证命令见 [开发.md](开发.md)。
