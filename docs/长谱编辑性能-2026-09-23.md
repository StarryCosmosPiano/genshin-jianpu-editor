# 长谱编辑性能核对（2026-09-23）

针对音符、小节增多后，输入、移动和延长音符逐渐变慢的问题，本轮消除了全谱重复查找和屏外页面的强制布局。沿用现有 SVG、字体测量和排版规则。

## 修改

- TXT 解析：延续音按声部和根事件分组，小节起点用二分查找；回填和弦时按声部、起止时间缩小候选范围，保留候选排序和原浮点容差。
- 源码定位：按声部和音高建立候选索引，已用候选通过后继索引跳过；行内分组只扫描一次，局部换调二分定位。保留同音数量、延续音优先级和琶音回查规则。
- 页面更新：在 DocumentFragment 中创建全部页面后一次替换；立即重排会取消文本变化产生的待执行计时器，避免重复解析。
- 打谱光标：先根据小节和声部找目标页，只在目标页读取屏幕坐标，避免唤醒所有屏外页面的布局。

对应稳定规则：JP-SLASH-009、JP-SEL-001、JP-LAY-016、JP-APP-002、JP-QA-001、JP-QA-005。

## 同机 Edge 实测

使用 1400×950 的无头 Edge，双声部键盘谱，每小节 20 个源音符。在倒数第二小节修改音符，包含序列化、重新解析、排版、SVG 更新、光标和试听发起的同步耗时。每档输入耗时为一次操作，首档包含首次编辑预热开销；不是跨机器保证或帧率指标。

| 小节数 / 源音符 / 页数 | 输入前 | 输入后 | 移动音符后 | 延长音符后 | 移动光标后 |
|---|---:|---:|---:|---:|---:|
| 32 / 640 / 4 | 220.7 ms | 221.6 ms | 115.3 ms | 93.6 ms | 2.7 ms |
| 128 / 2560 / 15 | 728.8 ms | 357.6 ms | 311.6 ms | 279.4 ms | 1.4 ms |
| 256 / 5120 / 29 | 2038.6 ms | 622.7 ms | 638.6 ms | 549.2 ms | 2.4 ms |

256 小节输入耗时下降约 69%。移动与延长没有修改前的配对基准，表中只报告修改后的绝对耗时。

独立 Node 解析预热中位数：256 小节约 1208 → 199 ms，四组长短谱、延续音和休止样本的模型及源码定位指纹一致。
独立源码映射在同一进程、同一 Score 上各预热两轮并取五轮中位数：32 小节 8.1 → 3.2 ms；128 小节 86.2 → 16.5 ms；256 小节 298.4 → 30.2 ms。旧参考实现由修改前读取的函数重建，完整候选对象身份、源码范围、声部和标记均对比一致。

第一轮排版采样表明，剩余时间主要用于生成整谱布局和 SVG，因此继续实施了下方的增量排版及页面复用。

- 核心回归通过，新增 `check:source-mapping` 覆盖重复同音的独立和弦、局部换调、合并琶音及 5120 音符来源定位。
- 浏览器回归全套脚本通过：选择、输入、声部、撤销重做、短/长三连音、MIDI 和 ABC。ABC 外部赞美诗 fixture 缺失，按原脚本跳过；两个内置合成样本通过。

## 第二轮：系统排版与 SVG 复用

同日继续优化后，加入以下机制：

- 钢琴双声部在节奏排版开启、无跨声部琶音时，用精确小节快照识别修改范围。保留未变谱行的排版、几何边界与节奏列；改变时值、音高或横向分组的谱行重新生成。总谱、单谱行、传统间距及跨声部琶音继续使用完整排版。
- 变高的谱行仍参与全局分页，页眉、页码和输入命中区域重新计算。字体、样式、页宽、全局记号等变化会让相关缓存失效；任何排版失败都会清理半成品缓存，保证下次可恢复。
- 复用的谱行通过稳定地址重新绑定新解析的 Chord、Note、Tuplet 和记号，点选、播放与后续编辑不会指向旧模型。快照采用精确序列化，不用有碰撞风险的哈希；已脱离当前小节树的连音终点也支持循环引用。
- 所有普通简谱的交互 SVG 改为逐节点更新，保留页面 wrapper、SVG 和未变图形；刷新反查映射，清理旧高亮、声部颜色和诊断层。独立导出与预览仍生成新 SVG。
- 同次 TXT 解析的音高来源列表供分声部、源码定位和文本高亮共享。每次编辑仍重新解析，保留既有节奏规范化与撤销语义。

复测条件与第一轮相同，以下为最终构建单次操作实测：

| 小节数 / 源音符 | 第一轮输入 | 第二轮输入 | 第二轮移动音符 | 第二轮延长音符 | 光标导航 |
|---|---:|---:|---:|---:|---:|
| 32 / 640 | 221.6 ms | 179.8 ms | 85.6 ms | 57.5 ms | 2.0 ms |
| 128 / 2560 | 357.6 ms | 248.7 ms | 203.6 ms | 183.4 ms | 2.6 ms |
| 256 / 5120 | 622.7 ms | 394.3 ms | 378.3 ms | 293.8 ms | 2.4 ms |

256 小节输入较第一轮再减少约 37%，较最初 2038.6 ms 减少约 81%。输入测试只重新生成 1 个钢琴系统，所有 29 个页面 SVG 对象保留。超长谱仍有约 0.4 秒的单次编辑延迟；完整解析、快照和剩余页面遍历仍有开销，本轮没有把刷新推迟到后台或跳过节奏规范化。

新增 `check:incremental-layout` 并纳入核心回归：16 种场景的增量页面树、模型引用、输入区域与完整重排一致，包括未变跨小节延音/三连音系统的真实复用、页高重分页、样式失效和异常恢复。新增 `painter-cache-check.mjs` 并纳入浏览器回归，覆盖 DOM 复用和新模型重绑。长谱测试还检查实际连续按键和撤销重做，并将所有页面与浏览器字体引擎完整排版的 SVG 逐节点对比（数值容差 1e-6）。

最终构建、核心检查、增量专项及浏览器全套回归均通过；ABC 外部 fixture 仍按第一轮说明跳过。最终阶段数据位于系统临时目录 `notation-performance-incremental-final.json`。
