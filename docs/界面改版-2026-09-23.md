# 原琴助手编辑器界面改版

## 已落地的交互

- 主界面、网页标题、帮助、Web 应用清单和 Tauri 安装名称统一为“原琴助手编辑器”。保留 Tauri identifier、文件关联、已有存储键和乐谱格式。
- 主题为跟随系统、浅色、深色，默认跟随系统。准确采用参考软件的紫色与金黄色；白色纸张、声部色和错误色独立。
- 谱面为主，顶部品牌与文档、文件菜单、保存导出；选择/打谱、撤销重做、播放、刻度和书写时值；底部位置、诊断、页码和缩放。
- 默认载入键盘谱示例并展开左侧文本，保留左右切换、拖动宽度和记忆；乐谱和排版使用互斥的右侧面板。小窗口保持主要编辑操作可见，窄屏使用抽屉，输入键盘占正常布局空间。
- 排版面板包含纸张比例/方向、基础/标题/署名字号、数字和弦、谱行间距、页眉、小节线、节奏与钢琴系统等设置。草稿约 200ms 合并为一次当前模型预览；应用才保存，取消恢复。关闭或切换脏面板时可应用、放弃或继续编辑。
- 进入打谱捕获切换前的有效位置；保留主活动声部、拍位置和和弦音高，灰色续音使用实际视觉段。文本有待处理编辑时先解析，再按活动端定位。没有位置时等待点击，不恢复旧文档或旧会话光标；切换保持视野且不试听。

## 实现边界

`bootstrap/workspace.ts` 组织界面事件；`ui/theme.ts` 管主题；`ui/inspector.ts` 管草稿关闭流程；
`editor/input-entry.ts` 解析进入位置。App 保留编辑与排版协调，复用现有文件、播放、撤销和格式入口。

排版预览不解析文本、不写源码或设置。纸张/字号的预览参数与 App 保存字段分离，字号变化时换排版器但复用当前 Score；
取消重新应用保存参数。保留 `.Layout` 指令与当前可见位置。主题只更新样式，保留 CodeMirror、Score 和页面对象。

新版布局在原 `jpeditor-render-settings` 增加 `workspaceLayoutVersion:2` 与 `codePaneWidth`。
旧设置第一次迁移为左侧文本展开；启动偏好可选择隐藏文本或恢复上次文件。主题独立存储在 `jpeditor.ui.theme`。

## 验证入口

- `npm run check:core`：记谱、格式、MIDI、三连音、源码映射、增量排版。
- `npm run check:browser`：全部编辑与导入导出回归，包含下方三个界面专项。
- `npm run check:ui`：打谱进入位置、右侧面板、主题与响应式专项。
- `node slashscore-shot.mjs`：独立 TXT 导入与排版交互样本。
- `node shot.mjs artifacts/ui/score-final.png`：实际谱面截图与诊断。
- `node notation-performance-check.mjs`：32/128/256 小节的编辑链路、SVG 复用、撤销重做及完整重排一致性。

`theme-check.mjs` 覆盖 1440、1280、900、390 像素宽度，检查主要按钮可见、浅深色/系统主题、白色纸张、
文本拖动与重启恢复、主题不重建编辑器或模型；截图输出到忽略目录 `artifacts/ui/`。
`inspector-check.mjs` 检查排版/纸张/字号草稿、取消计时器、立即应用、未应用修改提示及文档替换清理。
`input-entry-check.mjs` 覆盖谱面、文本反向选区、待解析修改、多选和弦、灰色延音及重排、三连音、跨页、无位置和换文档。

ABC 检查中的外部赞美诗 fixture 在本机不可用，脚本按既有规则跳过；内置合成样本可运行。
本次验证针对 Web 构建和本地 Edge；Tauri 产品配置已改名，未生成新的安装包。

## 反馈修正

- 文件菜单中的原生下拉框独立处理选择和方向键，点击下拉框不会关闭外层文件菜单；执行菜单按钮才关闭。
- 统一颜色用途：模式和选项选择为紫色；应用等主要执行按钮为金色；顶部保存、导出保持中性；已开启的打谱、附点与谱面锁定明确显示亮金色。取消、关闭等辅助操作保持中性。各状态的悬停/焦点都保持可读文字。
- 两个附点按钮直接显示“附点”，输入键盘只显示 `0`，悬停保留休止符说明。设置面板内容增加内边距。
- 打开排版自动展开最左侧样张，与文本谱通过标签切换；样张铺满左栏宽度，也可独立放大。CodeMirror 实例、内容和选区保持，关闭排版返回文本。
- 原琴助手原版图标来自相邻项目 `PC原琴辅助软件/resources/app.ico`：网页图标和 Windows 图标为原文件，网页 logo 无损提取其中 256px PNG，其余桌面图标由 Tauri 图标工具生成；参考项目未修改。
- 普通选择模式选中音后按空格，从当前音继续播放整段，再按停止。打谱模式保留空格前进，文本编辑器保留空格输入，长按不会反复触发播放。

反馈修正验证：构建通过；`ui-polish-check.mjs`、`space-playback-check.mjs`、`theme-check.mjs`、
`inspector-check.mjs`、`input-mode-check.mjs`、`selection-shot.mjs` 均通过。浅/深按钮对比度、原生下拉框真实键盘选择、
放大窗关闭与焦点返回都有断言，界面截图位于 `artifacts/ui/` 和 `artifacts/ui-polish/`。

## 验证结果与长谱对比

生产构建、核心回归、完整浏览器回归、独立 TXT 样本和界面专项通过。最后的纸张输入框样式调整后重新构建并复跑四档宽度主题检查。
主题的系统外观测试等待媒体查询变更事件生效，避免把异步浏览器通知误判为失败。

同机 Edge、1400×950、相同双声部测试谱；性能测试单独运行，未并行执行其他检查。

| 小节 / 音符 | 输入 | 移动音符 | 延长音符 | 光标 |
|---|---:|---:|---:|---:|
| 32 / 640 | 150.2 ms | 59.4 ms | 79.8 ms | 1.9 ms |
| 128 / 2560 | 231.0 ms | 187.4 ms | 163.3 ms | 1.3 ms |
| 256 / 5120 | 407.5 ms | 283.0 ms | 284.0 ms | 2.0 ms |

256 小节输入相对改版前 394.3 ms 约增加 3.3%，低于本次 10% 的回归门槛；移动和延长相对 378.3/293.8 ms 均未增加。
128 小节三个编辑操作也均未增加。32 小节首轮延长有波动，不作为长谱稳定性能结论。
这是一轮同机实测，不是跨机器延迟保证；超长谱仍有约 0.4 秒的输入开销。
测试同时通过一次编辑一次解析、光标不解析、29 页 SVG 复用、连续输入、撤销重做及完整重排一致性断言。
完整阶段报告：系统临时目录 `notation-performance-ui-final.json`，改版前基准为 `notation-performance-incremental-final.json`。

## 设置与交互补充

- 选中音符、下方打谱箭头及文本关联光标统一金色；取消选中恢复原有声部颜色。
- 播放与停止共用一个固定宽度按钮，加载中也可停止；翻页平滑滚动期间保留目标页码，手动滚动仍自动跟随。
- 外观合入设置，纸张、字号、墨色、每页行数、乐器名及混排小节号移到排版。
- 设置提供当前位置的分数/小数拍显示，7/4 拍可显示为 1.75 拍；实际节奏和谱面拍号不变。
- 设置可打开独立快捷键窗口，按场景录入按键、检查冲突、恢复默认并保存，帮助中的快捷键表同步当前配置。
- 钢琴/总谱花括号为传统左花括号路径；上下谱行间的小节线连接默认关闭，可在设置开启。


本轮设置改版验证：核心、输入、选音、面板、主题、MIDI/TXT/ABC、快捷键专项通过；
ABC 的真实赞美诗外部夹具缺失，合成用例通过。新增拍数测试使用实际 offset=3/4 音符，检查状态栏 7/4→1.75；
翻页使用逐帧和 MutationObserver 记录第 5→6 页整个过渡，并验证滚轮恢复跟随。

默认文本展开的两轮同机性能复测（256 小节 / 5120 音符）：输入 321.6–357.3 ms，移动 339.6–348.3 ms，
延长 262.1–339.9 ms，光标 1.7–3.1 ms。一次编辑一次解析、全部 25 页 SVG 复用、增量与完整排版一致、
连续输入及撤销重做均通过。与前一轮“文本默认折叠”报告的界面状态/页数不同，且移动/延长存在波动，
不据此宣称本轮达到持续耗时增加不超过 10% 的同配置门槛或进一步提速。
报告位于系统临时目录 `notation-performance-preferences-final.json` 和 `notation-performance-preferences-repeat.json`。
