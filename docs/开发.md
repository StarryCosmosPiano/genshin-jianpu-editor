# 开发

前置：Node ≥ 20、Rust（含 cargo）、（改文法时）JDK。

```bash
npm install

npm run dev          # Vite 开发服务器（仅前端）
npm run tauri dev    # 跑桌面应用（需 Rust）
npm run build        # tsc 严格检查 + 打包
npx tsc --noEmit     # 仅类型检查
npm run check:piano  # 双手语法 / MusicXML / 排版 / 播放 / MIDI 结构回归
npm run check:horizontal # 时值比例间距 / 小节借宽 / 目标小节数贪心重排
npm run check:midi   # MIDI 解析 / 推荐量化 / 三连音 / 双手 / BPM 往返回归
npm run check:midi:e2e # 构建后走 MIDI 导入对话框并检查双手网页预览

# 无头渲染/交互校验（用本地 Edge，免下载 chromium）
npm run build && node shot.mjs /tmp/out.png
```

项目结构与数据流见 [技术栈.md](技术栈.md)。
