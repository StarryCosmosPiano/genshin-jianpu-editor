# SF2 音源目录 / SoundFont directory

本项目支持 SF2 音源，但源码仓库和发行包不附带任何原神游戏音频或第三方
SoundFont。

- 桌面版：在「选项 → 播放音源（SF2）」中点击「打开音源文件夹」，放入你有权使用的
  `.sf2` 文件后点击「刷新音源」。
- 从源码构建网页端：可以把你有权使用的 `.sf2` 文件放入此目录后重新构建。这里的
  `.sf2` 文件已被 Git 忽略，不会意外提交。

This project supports SF2 playback, but the source repository and release
packages do not include Genshin Impact audio or any third-party SoundFont.

- Desktop app: open **Options → Playback source (SF2) → Open SoundFont
  folder**, add an `.sf2` file you are permitted to use, then refresh the
  catalog.
- Local web build: place an authorized `.sf2` file in this directory before
  building. Files ending in `.sf2` here are ignored by Git.
